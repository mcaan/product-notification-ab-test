# Data

This project uses the `_AB_Test_Data.csv` dataset provided as course material for Preeti Semwal's Udemy course **Complete Course on A/B Testing**.

## Data Access

The source dataset is not included in this repository because it is course-provided material and is not being redistributed here.

To reproduce the analysis:

1. Obtain the dataset through the Udemy course.
2. Download `_AB_Test_Data.csv`.
3. Place the file in this directory:

   `data/_AB_Test_Data.csv`

The analysis notebook loads the dataset from this repository-relative path.
